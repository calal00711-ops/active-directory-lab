Active Directory Security Lab
Project Overview

This project documents the deployment and administration of a Windows Server Active Directory environment within a VMware-based lab. The goal of the project is to gain hands-on experience with enterprise identity management, centralized authentication, DNS services, user administration, security monitoring, and troubleshooting.

The lab environment consists of:

Windows Server 2022 Domain Controller
Active Directory Domain Services (AD DS)
DNS Services
Windows 11 Client Workstation
VMware Virtualization
Lab Objectives
Deploy Active Directory Domain Services
Promote a Windows Server to a Domain Controller
Create and manage Organizational Units (OUs)
Create and administer user accounts
Configure centralized authentication
Configure DNS services
Join systems to the domain
Configure Group Policy settings
Investigate failed login attempts
Analyze Windows Event Logs
Automate administrative tasks using PowerShell
